# 🐾 Instituto iFollow - Sistema de Adoção de Animais

Este projeto é uma plataforma web desenvolvida para facilitar o processo de adoção e apadrinhamento de animais, conectando protetores a pessoas interessadas em dar um novo lar a pets necessitados. O sistema foca em usabilidade e acessibilidade, proporcionando uma interface intuitiva tanto para o usuário final quanto para o administrador.

## 🚀 Funcionalidades

O sistema está dividido em módulos principais para cobrir todas as necessidades de uma instituição de proteção animal:

- **🐶 Adoção:** Página dedicada para a listagem de animais disponíveis e formulário de solicitação de adoção.
- **🤝 Apadrinhamento:** Espaço para usuários que desejam apoiar financeiramente ou emocionalmente um animal sem a possibilidade de adoção imediata.
- **💰 Doações:** Área incentivando a contribuição financeira para a manutenção da causa animal.
- **⚙️ Painel Administrativo:** Área restrita para gestão de solicitações, controle de animais e administração do sistema.

## 🛠️ Tecnologias Utilizadas

Para a construção deste projeto, foram utilizadas as seguintes tecnologias:

- **HTML5:** Estruturação semântica de todas as páginas.
- **CSS3:** Estilização personalizada, garantindo a identidade visual e a responsividade do layout.
- **FontAwesome:** Implementação de ícones modernos para melhorar a navegação e a experiência do usuário (UX).

## 📂 Estrutura do Projeto

```text
projeto/
├── css/                # Arquivos de estilização (Main, Login, Admin)
├── fontawesome-free/   # Biblioteca de ícones
├── adote.html          # Página de adoção
├── apadrinhe.html      # Página de apadrinhamento
├── doe.html            # Página de doações
└── areaadm.html        # Área do administrador
```

## 💻 Como executar o projeto

Como este é um projeto de frontend estático, não é necessário instalar dependências. Para rodá-lo localmente:

1. Clone este repositório:
   ```bash
   git clone https://github.com/aureayohanna/projeto-instituto-ifollow.git
   ```
2. Navegue até a pasta do projeto.
3. Abra qualquer arquivo `.html` (ex: `adote.html`) no seu navegador de preferência.
